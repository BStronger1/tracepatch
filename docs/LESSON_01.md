# 第一课：读懂一次 Agent 执行

目标：能解释 `问题 → 模型动作 → 工具执行 → 观察 → 下一步动作 → 退出`。

1. 打开 `examples/synthetic.traj.json`，这是人工构造的测试夹具，不是真实模型运行。
2. 找到三个 assistant 动作：运行测试、读取代码、再次运行测试。
3. 运行 README 中的离线分析命令，检查报告里的 message_indices（从 0 开始）。
4. 思考：为什么“重复运行测试”不能直接判定死循环？如果期间修改了代码，判断是否应改变？
5. 思考：为什么退出状态 Submitted 不能证明补丁正确？需要什么外部证据？

下一课需要服务商、模型和预算信息；API Key 仅放入本机私有配置，不粘贴到聊天、不提交 Git。

用户贡献记录：逐步记录自己理解、修改、运行和判断了哪些部分。AI 辅助生成的代码必须能解释并验证后，才写为自己的项目能力。
