# 简历素材草稿：仅覆盖已实现内容

**TracePatch：Coding Agent 执行诊断与失败恢复实验工具**

- 基于 mini-swe-agent 构建本地 Docker 执行与独立验证流程，接入模型 API，记录执行轨迹、补丁、任务哈希与运行快照。
- 实现动作格式诊断、输出截断识别及定向恢复反馈；实现带进程锁、原子写入和未知费用保留的请求预算账本。
- 建立 3 个开发任务并完成同配置双组实验，分别报告补丁正确性、正常提交、调用与报价估算；另实现完整工具输出留存与有界预览模块，尚未验证其模型效果。
- 扩展三文件任务队列修复与清单式源码导出，设计 8 组业务契约测试，通过逐模块回归注入验证测试有效性；实测恢复组补丁通过，但未在步数上限内正常提交。
- 接入 Requests 历史真实 issue：冻结源码与镜像，隔离参考修复与独立回归，导出允许的源码并验证；从真实轨迹复现输入超限，实现保留任务和最近完整交互的有界上下文选择。修复效果按公开报告表述，不写标准基准分数。

这是开发中素材。已有小型多文件任务和一个真实仓库接入样本；正式投递前仍需更多仓库任务、重复独立评估，以及本人解释和修改关键代码的准备。
不使用“成功率提升 33%”“显著降低成本”“社区广泛使用”等未经验证表述。代码由 AI 辅助开发；面试中准确说明自己负责的需求、设计决策、实验理解与验证工作。
