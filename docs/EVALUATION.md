# 实验协议（初稿）

- 首次运行是环境冒烟测试，不用于宣传能力。
- 开发集用于选择策略；独立测试集不得用于反复调参。
- 固定上游 commit、容器镜像摘要、模型标识、提示词、任务列表、超时与调用预算。
- 原始基线与改进版共用任务与资源约束；压缩/恢复产生的额外模型调用也计入成本。
- 先 5 个冒烟任务，再依据预算确定开发与测试规模；不预先承诺提升。
- 成功由 Agent 无法修改的外部验证器判定；Submitted 仅为退出状态。
- 基础设施故障单列，明确重跑规则，不静默剔除失败任务。
- 报告成功数/总任务数、Token、费用、耗时、调用数；未知成本不得记为零。
- 固定随机配置并尽可能重复试验；小样本结果只代表所选任务子集。
- 轨迹可能含源码与敏感内容，公开前人工检查；任务答案和隐藏测试不得进入 Agent 上下文。

已记录用户提供的 DMXAPI / qwen3.8-flash 配置及报价，见 configs/model.json。待确认首轮费用上限、接口可用性与缓存计费口径。缓存创建与命中在供应商计费语义和 usage 字段核实前，不与普通输入重复累加，也不预估缓存折扣。
