## 本轮改变了什么

旧接口要求模型用自然语言文本输出 bash 代码块，模型多次返回残缺 XML 包装。
新增原生模式通过 tools schema 请求 bash 函数，严格解析 tool_calls JSON，匹配工具结果 id，
并在上下文删减时保留调用与结果配对。不从无效结构或正文自动猜测可执行命令。
原有文本模式和全部失败记录仍保留。

任务前完成两轮协议探测，结果回传使用明确标注的模拟输出，没有执行 shell。
随后真实任务在无网络容器中执行，导出白名单源码到干净副本，重新注入独立验证器。
因此探测成功与修复成功是两种不同证据，未混算。

## 结论边界

历史文本协议的五次尝试见 [完整负结果](requests-study-001.md)。与历史版本相比，本轮更改了协议、接口提示与实现；不是严格随机对照，不能将差异全归因于一个变量。
两次成功覆盖一个小型历史公开 issue，且有可见复现辅助，可能存在训练数据污染。
使用自定义离线回归，未运行上游完整测试集；没有 SWE-bench 分数、跨仓库成功率或成本下降结论。
Agent 的修改也不要求与官方最小补丁逐行一致，验证通过不代表没有测试范围外的回归。
